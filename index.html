About

From a sixth-semester RL course to three first-author papers.

I graduated from DA-IICT, Gandhinagar, with a B.Tech. (Honours) in Information and Communication Technology and a minor in Computational Science. Reinforcement learning became my subject in the sixth semester, in Prof. Abhishek Jindal's course, where I earned a perfect 10/10. That course turned into a research internship and my B.Tech. major project under him.

Prof. Jindal works on both RL and wireless communication, and our research grew out of that overlap. We read the literature together, found the places where existing RL formulations for wireless optimization fell short, and set out to fix them. I went from struggling to see how anyone had framed a beamforming problem as an MDP to designing my own methods: first for fairness, then for fast adaptation in environments that do not sit still.

Today I work as a full-stack Java developer on Oracle Fusion HCM. In parallel I build RLHF pipelines (PPO, TRPO, GRPO) from scratch, because the policy-optimization ideas I use for metasurfaces are the same ones used to post-train language models and agents.

Rate optimization in distributed RIS-aided MIMO with Soft Actor-Critic

IEEE VTC2025-Fall · published
The gapJointly designing beamforming and phase shifts across several distributed surfaces is non-convex, with unit-modulus constraints coupling the surfaces. Iterative solvers have to re-run for every channel realization.
My contributionA continuous-control MDP solved with Soft Actor-Critic. A single learned policy outputs the whole configuration in one forward pass, and entropy regularization keeps it exploring a multi-modal phase landscape.

Max-min fairness in stacked intelligent metasurfaces via deep RL

IEEE TMLCN · minor revision submitted
The gapExisting max-min designs for SIM-assisted downlinks use alternating optimization (geometric programming plus gradient descent-ascent), which must be re-solved for every channel realization. Prior DRL work on SIM optimized sum-rate, which can starve the weakest users.
My contributionA deep RL formulation for the non-smooth max-min objective, where only the worst-off user drives the reward. It jointly learns transmit power and wave-domain phase shifts across every stacked layer, and it is objective-agnostic, so it carries over to other fairness-constrained allocation problems.

Meta-RL with GRPO for fast adaptation to changing channels

in preparation · targeting IEEE TVT / TMLCN
The gapA DRL policy trained for one set of channel conditions degrades when those conditions drift, and retraining from scratch is impractical in sequential, non-stationary environments like a real wireless link.
My contributionA meta-RL framework built on Group Relative Policy Optimization. It is critic-free and uses group-normalized advantages, so a meta-learned policy adapts to a new channel regime in a few updates without waiting for a value function to catch up.

Lab notebook

The morning a few micrometres changed everything

Entry · final week before submission

We were adding the last results to the paper. Re-reading the simulation code one morning, I found a single wrong multiplication. It changed a distance in the channel model by only a few micrometres, but in a stacked metasurface those distances enter the phase terms, and every result moved.

Weeks of analysis were gone. Prof. Jindal sat with me, re-checked the code line by line, and we rebuilt the GRPO framework on the corrected model. The new results were stronger than the ones we had lost.

What I kept from that morning: in high-dimensional optimization, correct model > good optimizer. I now verify the environment before I trust anything a policy tells me.
